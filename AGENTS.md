Jazz Booking App

Projekt

Private Webanwendung zur Unterstützung beim Booking von Jazzbands.

Langfristige Funktionen:
	•	Jazzclubs und Kontakte verwalten
	•	Club-Datenbank aufbauen
	•	Booking-Anfragen verwalten
	•	KI-gestützte, personalisierte Booking-E-Mails erstellen
	•	später E-Mail-Versand integrieren

Das Projekt wird schrittweise entwickelt.

Tech Stack
	•	Frontend: Next.js, React, TypeScript
	•	Backend: Python, FastAPI
	•	Datenbank: PostgreSQL

Frontend und Backend kommunizieren über eine API.

Entwicklungsregeln
- Der Entwickler möchte den Code selbst schreiben und nicht einfach fertigen Code übernehmen.
- Gib neuen Code nur in sehr kleinen Blöcken von wenigen Zeilen vor.
- Warte nach jedem kleinen Schritt, bis der Entwickler ihn selbst geschrieben hat.
- Erkläre jede neue Codezeile und ihren Zusammenhang mit dem restlichen Projekt.
- Erkläre neue Begriffe, Konzepte und Syntax, bevor sie vorausgesetzt werden.
- Arbeite langsam, geduldig und Schritt für Schritt.
- Vermeide große fertige Codeblöcke, außer der Entwickler bittet ausdrücklich darum.
- Bei Fehlern zuerst erklären, was falsch ist und warum, bevor eine fertige Lösung gezeigt wird.
- Das Ziel ist nicht nur eine funktionierende Anwendung, sondern das Verständnis des Codes und der Architektur.
	•	Implementiere nur die aktuell angeforderte Funktion.
	•	Keine zukünftigen Features ohne Anweisung vorwegnehmen.
	•	Bestehenden Code vor Änderungen prüfen.
	•	Einfache, saubere und wartbare Lösungen bevorzugen.
	•	Keine Secrets oder API-Keys im Repository speichern.
	•	Environment Variables für Konfiguration verwenden.
	•	Datenbankänderungen sauber durchführen.

KI und E-Mail

KI wird später für personalisierte Booking-E-Mails und Club-Recherche verwendet.

KI-generierte Informationen dürfen nicht ungeprüft als Fakten behandelt werden.

E-Mails sollen später erst nach manueller Freigabe versendet werden.

Arbeitsweise

Das Projekt wird iterativ entwickelt. Folge den jeweiligen Anweisungen Schritt für Schritt und halte Änderungen möglichst klein und nachvollziehbar.
